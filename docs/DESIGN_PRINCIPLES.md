# 디자인 원칙

## UX / UI 기본 원칙

### 첫 화면

- 문장 하나 + 여백
- 설명 없음
- 버튼 최소화

### 침묵 UX

- 아무 말 없는 화면도 정상 상태
- 침묵에 의미 부여 ❌

### 공유 UX

- 인스타 스토리/피드 비율 지원
- 문장 + 배경 중심
- 로고/브랜딩 최소화

### 공유 Export 기능

| 포맷 | 비율 | 용도 |
|------|------|------|
| PNG | 9:16 | 인스타 스토리 |
| PNG | 1:1 | 인스타 피드 |
| PNG | 4:5 | 인스타 세로형 피드 |

- 문장 중앙 정렬 + 여백 강조 레이아웃
- 워터마크: 기본 OFF, 사용 시 아주 미묘하게만

## 글로벌 시장 대응 설계

### 언어 전략

- 직역 ❌
- 현지 감각 재작성(Transcreation) ⭕
- 다국어 구조는 처음부터 포함 (i18n 지원)
- 문장 테이블 언어별 분리

### 문화 민감도 필터

- 종교/정치 단어 자동 차단
- 강한 감정 단어 제한
- 보편 감정만 사용

### 영문 톤

- 영어 문장도 "관찰자" 톤 유지
- 조언/판단 어조 금지 (동일 원칙 적용)

## 수익 모델 설계

### 구독

- 월 구독 (커피 한 잔 수준)
- 무료 체험 기간: 7일
- 자동 갱신
- 취소 쉬움

### 기본 기능 차별 금지

- 유료 = 문장 추가 ❌ ("프리미엄 문장" 같은 구조 금지 — 철학 침해)
- 유료 = 꾸미기 요소 ⭕
- 기능 제한 ❌
- 감정 차별 ❌

### 부가 수익

- 이벤트성 배경
- 테마 요소
- 단발성 구매

> 기본 경험은 항상 충분해야 한다. 추가 결제는 '꾸미기'이지 '해결'이 아니다.
