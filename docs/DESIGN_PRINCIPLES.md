# 디자인 원칙

## UX / UI 기본 원칙

### 첫 화면

- 문장 하나 + 여백
- 설명 없음
- 버튼 최소화

### 침묵 UX

- 아무 말 없는 화면도 정상 상태
- 침묵에 의미 부여 ❌

### 공유 UX

- 인스타 스토리/피드 비율 지원
- 문장 + 배경 중심
- 로고/브랜딩 최소화

---

## 앱 서비스 전제 설계

### 플랫폼

- iOS / Android 앱 우선
- 알림 중심 경험

### 계정 / 온보딩

- 최소 정보
- 철학 먼저 전달
- "이 서비스는 행동을 요구하지 않습니다" 명시

---

## 글로벌 시장 대응 설계

### 언어 전략

- 직역 ❌
- 현지 감각 재작성(Transcreation) ⭕

### 문화 중립성

- 종교/정치/도덕 판단 배제
- 보편 감정만 사용

---

## 수익 모델 설계

### 기본

- 월 구독 (커피 한 잔 수준)
- 기능 제한 ❌
- 감정 차별 ❌

### 부가 수익

- 이벤트성 배경
- 테마 요소
- 단발성 구매

> 기본 경험은 항상 충분해야 한다. 추가 결제는 '꾸미기'이지 '해결'이 아니다.
