# 제품 가이드

## 서비스명 후보

- 기억 사이
- 다시, 기억

## 서비스가 해결하는 문제

- 경험은 많지만 정체성으로 축적되지 않음
- 감정과 취향이 소비되듯 사라짐
- 바쁜 일상 속에서 나에게 집중할 여백 부재

## 핵심 가치 키워드

침묵 · 여백 · 재접속 · 관찰 · 비강요

---

## MVP 기능 체크리스트

### 포함

- 알림 (아침 8시 / 점심 1시 / 저녁 6시)
- 가끔 변주 (하루 1회만 오는 날 등)
- 한 문장 메시지
- 침묵 (아무 말 없는 날 허용)
- 사용자 기록 (강요 없음, 설명 없음)

### 제외

- 감정 점수
- 성장 지표
- 목표 관리
- 분석 리포트
- 비교 요소

> MVP는 기능 최소화를 최우선으로 설계한다. '덜 하는 것'이 품질이다.

---

## 알림 시스템 설계

### 기본 알림 패턴

- 아침 / 점심 / 저녁 고정
- 첫 설정 시 기본 ON
- 언제든 OFF 가능

### 알림 문장 규칙

- 한 문장
- 행동 유도 ❌
- 클릭 요구 ❌
- 읽고 끝나도 OK

### 변주 규칙

- 빈도: 매우 낮음 (주 1회 이하)
- 형태:
  - 하루 1회만 알림
  - 과거의 내가 남긴 문장
  - 침묵

### 침묵 설계

> 시스템은 의도적으로 메시지를 보내지 않는 날을 설계에 포함한다.
> 침묵은 버그가 아니라 기능이다.

- 침묵 빈도: 변주 규칙과 동일하게 주 1회 이하
- 침묵 시 앱 화면: 여백만 표시, 추가 설명 없음
- 침묵에 의미 부여 ❌

## 문장 엔진 아키텍처

### 문장 소스 구분

| 소스 | 설명 |
|------|------|
| 기본 문장 라이브러리 | 수동 큐레이션된 문장 풀 |
| AI 생성 문장 | 관찰자 톤 규칙에 따라 실시간 생성 |
| 사용자 과거 문장 | 유저가 남긴 기록 중 재접속 대상 |

### 생성 로직 규칙

- 하루 3회 중 동일 문장 중복 금지
- 최근 7일 내 동일 문장 반복 금지
- 변주 발생 확률: 5~10%

### 생성 모드

| 모드 | 시간 | 톤 특성 |
|------|------|---------|
| 아침 모드 | 08:00 | 조용한 시작 |
| 점심 모드 | 13:00 | 가벼운 관찰 |
| 저녁 모드 | 18:00 | 여운 있는 마무리 |
| 변주 모드 | 랜덤 | 과거 문장 또는 침묵 |

## 사용자 기록 기능

### 기록 입력

- 텍스트 1~3줄 제한
- 날짜 자동 저장

### 기록에서 제외

- 감정 태그 ❌
- 카테고리 ❌
- 폴더 ❌

> 기록은 정리 도구가 아니라 "흔적"이어야 한다.

---

## 문장 톤 가이드

### 문장 스타일

- 15~40자
- 느낌표 ❌
- 물음표 ❌ (거의 사용 안 함)

### 언어 규칙

- "너는 / 당신은" ❌
- "사람은 / 어떤 날은 / 우리는" ⭕

### 금지 표현

- 조언
- 판단
- 해석
- 해결책 제시

> 문장은 항상 해석의 여백을 남길 것. '맞는 말'이 아니라 '겹쳐질 수 있는 말'을 생성할 것.
