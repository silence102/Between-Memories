# 제품 가이드

## 서비스명 후보

- 기억 사이
- 다시, 기억

## 서비스가 해결하는 문제

- 경험은 많지만 정체성으로 축적되지 않음
- 감정과 취향이 소비되듯 사라짐
- 바쁜 일상 속에서 나에게 집중할 여백 부재

## 핵심 가치 키워드

침묵 · 여백 · 재접속 · 관찰 · 비강요

---

## MVP 기능 체크리스트

### 포함

- 알림 (아침 8시 / 점심 1시 / 저녁 6시)
- 가끔 변주 (하루 1회만 오는 날 등)
- 한 문장 메시지
- 침묵 (아무 말 없는 날 허용)
- 사용자 기록 (강요 없음, 설명 없음)

### 제외

- 감정 점수
- 성장 지표
- 목표 관리
- 분석 리포트
- 비교 요소

> MVP는 기능 최소화를 최우선으로 설계한다. '덜 하는 것'이 품질이다.

---

## 알림 시스템 설계

### 기본 알림 패턴

- 아침 / 점심 / 저녁 고정
- 첫 설정 시 기본 ON
- 언제든 OFF 가능

### 알림 문장 규칙

- 한 문장
- 행동 유도 ❌
- 클릭 요구 ❌
- 읽고 끝나도 OK

### 변주 규칙

- 빈도: 매우 낮음 (주 1회 이하)
- 형태:
  - 하루 1회만 알림
  - 과거의 내가 남긴 문장
  - 침묵

---

## 문장 톤 가이드

### 문장 스타일

- 15~40자
- 느낌표 ❌
- 물음표 ❌ (거의 사용 안 함)

### 언어 규칙

- "너는 / 당신은" ❌
- "사람은 / 어떤 날은 / 우리는" ⭕

### 금지 표현

- 조언
- 판단
- 해석
- 해결책 제시

> 문장은 항상 해석의 여백을 남길 것. '맞는 말'이 아니라 '겹쳐질 수 있는 말'을 생성할 것.
